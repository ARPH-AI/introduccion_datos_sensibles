# Introduccion al uso de datos sensibles

Materiales desarrollados en español gracias al financiamiento de Invest in Open Infrastructure al proyecto "Infraestructura para el uso responsable de datos de salud en Argentina: construcción de capacidades y comunidades en torno a datos sensibles" para la sensibilización y capacitación en el uso de datos sensibles con especial atención a los datos de salud.
