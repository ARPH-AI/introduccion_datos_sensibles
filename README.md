# Introduccion al uso de datos sensibles

Materiales desarrollados en español gracias al financiamiento de Invest in Open Infrastructure al proyecto "Infraestructura para el uso responsable de datos de salud en Argentina: construcción de capacidades y comunidades en torno a datos sensibles" para la sensibilización y capacitación en el uso de datos sensibles con especial atención a los datos de salud.

## Documentos disponibles
- [Introducción al uso responsable de datos sensibles](https://zenodo.org/records/17143651): El propósito de este documento es brindar a la comunidad de investigación y gestión de datos sensibles una introducción al área del Uso Responsable de datos sensibles. Esto incluye no sólo definiciones conceptuales sino también los dilemas éticos que esto conlleva así como estrategias y herramientas para superar dificultades y mitigar riesgos en este tipo de trabajos. 
- [Guía de incorporación y desvinculación](https://zenodo.org/records/17143696): documento guía para integrantes de la comunidad ARPHAI, que puede servir de inspiración para otras comunidades en torno a datos.
